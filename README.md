# Реставрация ванн — Новосибирск

Статический лендинг для Анатолия Маслакова. Сайт готов для публикации через GitHub Pages.

## Что внутри

- `index.html` — разметка страницы
- `styles.css` — адаптивный дизайн
- `script.js` — сравнение «до/после», калькулятор цены, копирование номера
- `assets/` — фотографии и favicon

## Как открыть локально

Можно просто открыть `index.html` в браузере.

Для локального сервера:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него все файлы из этой папки.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Сохраните. Через несколько минут GitHub покажет адрес сайта.
